1. What is JavaScript? 
--> JavaScript is a powerful programming language that makes websites interactive.
    JavaScript is a single-threaded language that executes one task at a time.
    It is an interpreted language which means it executes the code line by line.

2.Why use JavaScript?    
--> It's everywhere: It's the most popular language for web development and runs in all modern browsers
    It's versatile: You can use it for front-end development and back-end development with tools like Node.js.

3.Limitations And Advantages Of JavaScript
--> Limitations of JavaScript 
      -JavaScript could not used for networking applications
      -JavaScript doesn't have any multithreading capabilities   
--> Advantages of JavaScript
      - JavaScript runs in the browser without needing server communication for most tasks
            (Example: Form validation before submitting data to the server)
      - Easy to Learn and Implement
         Syntax is simple compared to many programming languages.
      - Event-Based Programming
         Makes it easy to respond to user actions like clicks, mouse movements, or keyboard input.

9.Loops
--> -- for: Repeats a block of code a fixed number of times using a counter.
    -- while: Repeats a block of code as long as a condition is true (checks before running).
    -- do...while: Runs a block of code at least once, then repeats while the condition is true.
        for = count-based, while = condition-first, do...while = condition-last.

12.Array
 -- array used to store ordered collections of elements that can be accessed 
    using an index (0-based position)

--> Difference Between filter() and find()
     - filter()
        Returns a new array of all elements that match the condition
     - find()
        Returns the first matching element
   - map() → Transforms each element and returns a new array
   - reduce() → method transforms an array into a single value by applying a callback function on each element
   - push() → Adds an element to the end.
   - pop() → Removes the last element.
   - shift() → Removes the first element. 
   - unshift() → Adds an element at the beginning.
   - concat() → Merges two or more arrays.
   - join() → Converts array elements into a string.
   - slice() → Returns a part of the array (does not modify original).
   - splice() → Adds/removes elements at a specific index.
   - sort() → Sorts array elements.Example arr = [3,2,1]   arr.sort() result [1,2,3]
   - reverse() → Reverses array order.
   - filter() → Selects elements that pass a condition and returns them

       - toLowerCase() → Converts string to lowercase.
       - trim() → Removes spaces from both ends.
       - trimStart() / trimEnd() → Removes spaces from start / end. 
       - concat() → Joins two or more strings.
       - split() → Splits string into array.

15.JavaScript Storage 
     - Local Storage (localStorage) 5-10MB
        Stores data permanently in the browser (until manually cleared)
     - Session Storage (sessionStorage) 5MB
         Stores data only for one session.
         Data is deleted when the browser tab is closed.
     - Cookies (document.cookie) 4KB
         Small pieces of data stored in the browser.
         Have expiry dates and are sent with every HTTP request to the server.
         
16. Event
   Event is something that happens in the browser (user action or system-generated)

   - Mouse Events
      onclick → when user clicks.
      ondblclick → double-click.
      onmouseover → when mouse enters element.
      onmouseout → when mouse leaves.
      onmousemove → when mouse moves.

   - Keyboard Events
      onkeydown → key pressed down.
      onkeyup → key released.
      onkeypress → key pressed (deprecated, use keydown).

   - Form Events
      onsubmit → when form is submitted.
      onchange → when input changes.
      oninput → when typing in input field.
      onfocus → when input is focused.
      onblur → when input loses focus.

   - Window Events
      onload → when page finishes loading.
      onresize → when window is resized.
      onscroll → when page is scrolled.
      onerror → when error occurs.
